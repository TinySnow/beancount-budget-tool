# v6 实施状态

截至 2026-10-19，v6 是**可运行的开发预览**。计算规则以[用户需求](REQUIREMENTS.md)和[冻结架构](budget-v6-review.md)为准；操作从[QUICKSTART](../QUICKSTART.md)开始。本页只记录当前能力和验收边界。

## 已可运行

| 范围 | 当前能力 |
|---|---|
| 来源与标签 | 通过 Beancount booked 事实和账本行号核对 `budget`、`fund`、`tracking`；拆分金额必须精确守恒，重复认领或来源变化会拒绝。 |
| 分类与目标 | 审计费用／收入类别、消费目标及子树目标、用途月目标和已审净划拨；私人默认分类规则留在私人侧文件。 |
| 资产用途 | H 真实库存按期初和逐笔来源重放；完整已审期初可供简单同币 H 转账继承用途，混合用途部分转出可显式配置顺序，否则待审；K 申赎只表示账面累计和已审用途变动，不声称基金份额或市值；证券池可声明名义本金，并可选择亏损由余款用途承担、显示负数及警告。 |
| 责任与可花 | 审计已记信用卡责任、还款、代垫、简单期初未结 ID、白名单同日结算及直接支付范围；未结已审单位代垫单列应收，不重复扣债务或提前加入现金；已审报告货币专项卡债可绑定当前可支付现金，联合核对覆盖容量，剩余缺口进入实际可花；外币未清卡债可绑定有效的报告货币锁定账单；证据齐全的报告日可签发实际可花。 |
| 报表 | 已审自然月可汇总实际可花、消费目标差、用途 Q−G、账户用途和专题；可按用途查看原币余额与账户分布，默认用途及零余额用途也显示，证券池账面成本、K 申赎净变动各自列示；来源或指标缺证据时列待审及位置。文本、JSON 和终端浏览共用月报入口。 |
| 逐月迁移 | 可只读比较改写前后的完整账本，限定目标月、检查 booked 财务事实与 v6 标签；导入新交易后可续用已审分类并生成待审清单。 |
| 首月配置 | `beancount-budget-init` 提取账户、期初和行内名称，生成集中填写表；使用者确认账户、期初用途、默认规则、目标及截止日完整性后，编译全部基础侧文件。未完成的决定和源标签问题保留待审及行号，不生成已审月报。 |
| 交易审阅 | TUI 按 `e` 可逐项填写分类／H 资产用途，明确批准后保存新配置并复审；`beancount-budget-review` 将当前待审分类与 H 资金用途导出为填写表；只填名称、理由及明确批准，工具生成来源认领、保存新配置并重跑月报。支持分批批准，其他问题继续待审。 |
| 下一月准备 | `beancount-budget-next-month` 复用最新配置和原 cutover，提取待确认目标、新账户／币种及未定支付范围；原交易认领继续使用，余额不重置。也可在月内审阅后，对最新配置补月末声明。 |
| TUI | 同一月报入口可重算、中文关键词筛选、选择待审并查看完整原因／位置／来源，以及切换显式提供的月份配置；筛选保留待审总数及报告负数警告。错误后清除旧数字，修复后可重试。 |
| 区间与导出 | `beancount-budget-report` 重审连续月份，比较逐月目标与月末可花、累计实际流量并展示期末用途余额；支持文本、完整 JSON 和 CSV。缺月拒绝，任一月份待审时不生成区间数字。 |

主要入口：`beancount-budget-tool --config ...`、`beancount-budget-audit`、`beancount-budget-review-month`。配置和示例见[月报说明](v6-monthly-report.md)及[公开标签示例](../examples/v6/labeling.bean)。
